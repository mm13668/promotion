### 接入百度OCPC回传接口
   接口文档地址：https://ocpx.baidu.com/developer/ocpc-doc/api/api-doc/api-interface/
   读取这个页面的接口内容
    ```
    (1) 请求地址: https://ocpc.baidu.com/ocpcapi/api/uploadConvertData
    (2) 示例，若同一个点击有多个转化,请将转化类型分开回传,如下所示
    curl   -H "Content-type: application/json" -X POST  -d '{
            "token": "your token",
            "conversionTypes": [
                {
                    "logidUrl": "http://www.bb123.com/12345?XX=XXX&bd_vid=1111",
                    "newType": 3
                },
                {
                    "logidUrl": "http://www.bb123.com/12345?XX=XXX&bd_vid=1111",
                    "newType": 27
                },
                {
                    "logidUrl": "http://www.bb123.com/12345?XX=XXX&bd_vid=2222",
                    "newType": 3
                }
            ]
        }'  https://ocpc.baidu.com/ocpcapi/api/uploadConvertData
    ```

   这个回传接口实现要放在utils目录下，之后还会接入更新广告平台的回传的，所以代码你要写兼容，可以参考工厂模式的设计模式等等

### 自动回传实现
landing_visits.link_id == promotion.id

定时器每10分钟自动回传判断一次，条件：landing_visits.duration > promotion.【浏览时长大于】&& 并且还没回传的 && 最近1小时的记录

### 手动回传实现

    表 landing_visits 新增复制时间字段，是否回传字段，在页面/Users/wangjingjun/work/promotion/web/src/view/promotion/landingVisit/index.vue 展示，如未回传的话，点击【未回传】，弹出框确认是否回传，点击确认，就需要调用对应广告平台的回传接口
